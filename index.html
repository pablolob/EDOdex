Cheatsheet de teclado

El texto libre busca en título, ID, autor, fuente, contenido Markdown y datos personales. Los filtros se combinan con AND; separa valores con coma para usar OR.

Campos

id:, title:, author:, source:, chapter:, section:, exercise:, topic:, competency:, notes:, tag:, status:, c:, t:, blocked:, captured: y starred:.

Ejemplos

  • status:draft c:2..3
  • competency:verificar.sustitucion-directa -blocked:yes
  • author:"Dennis G. Zill" captured:no

Enter / Espacio
Abrir la ficha o abrir/cerrar la sección enfocada del lector.
