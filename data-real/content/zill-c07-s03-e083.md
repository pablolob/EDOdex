
## Enunciado

a) Suponga que el teorema 7.3.1 se cumple cuando el símbolo $a$ se remplaza por $ki$, donde $k$ es un número real e $i^2 = -1$. Demuestre que $\mathcal{L}\{t e^{kti}\}$ se puede usar para deducir
$$\mathcal{L}\{t \cos kt\} = \frac{s^2 - k^2}{(s^2 + k^2)^2}$$
$$\mathcal{L}\{t \sin kt\} = \frac{2ks}{(s^2 + k^2)^2}$$

b) Ahora use la transformada de Laplace para resolver el problema con valores iniciales $x'' + \omega^2 x = \cos \omega t$, $x(0) = 0$, $x'(0) = 0$.
