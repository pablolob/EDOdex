
## Enunciado

Considere el modelo de un sistema resorte/masa no lineal sin amortiguamiento dado por $x'' + 8x - 6x^3 + x^5 = 0$. Use un programa de solución numérica para analizar la naturaleza de las oscilaciones del sistema que corresponden a las condiciones iniciales:
$$x(0) = 1, \, x'(0) = 1; \quad x(0) = -2, \, x'(0) = \frac{1}{2};$$
$$x(0) = \sqrt{2}, \, x'(0) = 1; \quad x(0) = 2, \, x'(0) = \frac{1}{2};$$
$$x(0) = 2, \, x'(0) = 0; \quad x(0) = -\sqrt{2}, \, x'(0) = -1.$$
