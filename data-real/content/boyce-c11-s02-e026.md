
## Enunciado

Para cada una de las siguientes condiciones en la frontera, encuentre el menor eigenvalor (la carga de pandeo) de $$y^{\text{iv}} + \lambda y'' = 0$$ y también halle la eigenfunción correspondiente (la forma de la columna pandeada).

a) $$y(0) = y''(0) = 0, \quad y(l) = y''(l) = 0$$
b) $$y(0) = y''(0) = 0, \quad y(l) = y'(l) = 0$$
c) $$y(0) = y'(0) = 0, \quad y(l) = y'(l) = 0$$
