
## Enunciado

Demuestre cada una de las siguientes leyes del álgebra matricial:
(a) $\mathbf{A} + \mathbf{B} = \mathbf{B} + \mathbf{A}$ \quad (b) $\mathbf{A} + (\mathbf{B} + \mathbf{C}) = (\mathbf{A} + \mathbf{B}) + \mathbf{C}$
(c) $\alpha(\mathbf{A} + \mathbf{B}) = \alpha\mathbf{A} + \alpha\mathbf{B}$ \quad (d) $(\alpha + \beta)\mathbf{A} = \alpha\mathbf{A} + \beta\mathbf{A}$
(e) $\mathbf{A}(\mathbf{BC}) = (\mathbf{AB})\mathbf{C}$ \quad (f) $\mathbf{A}(\mathbf{B} + \mathbf{C}) = \mathbf{AB} + \mathbf{AC}$
