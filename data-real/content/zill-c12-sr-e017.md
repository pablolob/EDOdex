
## Enunciado

Utilice la sustitución $u(x, y) = v(x, y) + \psi(x)$ y el resultado del problema 16 para resolver el problema de valor de frontera
$$\begin{aligned}\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} &= -2, \quad 0 < x < \pi, \quad 0 < y < \pi \\ u(0, y) &= 0, \quad u(\pi, y) = 0, \quad 0 < y < \pi \\ u(x, 0) &= 0, \quad u(x, \pi) = 0, \quad 0 < x < \pi\end{aligned}$$
