
## Enunciado

Demuestre que la ecuación $y' = f(x, y)$ es homogénea si $f(x, y)$ es tal que

$$f(x, tx) = f(1, t),$$

en donde $t$ es un parámetro real. Aplique este hecho para determinar si cada una de las ecuaciones siguientes es homogénea.

a) $y' = \frac{x^3 + xy + y^3}{x^2 y + xy^2}$

b) $y' = \ln x - \ln y + \frac{x + y}{x - y}$

c) $y' = \frac{(x^2 + 3xy + 4y^2)^{1/2}}{x + 2y}$

d) $y' = \frac{\sin(xy)}{x^2 + y^2}$
