
## Enunciado

El modelo $mx'' + kx + k_1x^3 = F_0 \cos \omega t$ de un sistema no amortiguado resorte/masa forzado en forma periódica se llama **ecuación diferencial de Duffing**. Considere el problema con valores iniciales $x'' + x + k_1x^3 = 5 \cos t$, $x(0) = 1$, $x'(0) = 0$. Use un programa de solución numérica para investigar el comportamiento del sistema para valores de $k_1 > 0$ que van de $k_1 = 0.01$ a $k_1 = 100$. Exprese sus conclusiones.
