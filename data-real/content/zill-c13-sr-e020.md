
## Enunciado

Resuelva el problema del valor en la frontera
$$\frac{\partial^2 u}{\partial r^2} + \frac{1}{r}\frac{\partial u}{\partial r} - \frac{1}{r^2}u + \frac{\partial^2 u}{\partial z^2} = 0, \quad 0 < r < 1, \quad 0 < z < 1$$
$$u(1, z) = 0, \quad 0 < z < 1$$
$$u(r, 0) = 0, \quad u(r, 1) = r - r^3, \quad 0 < r < 1.$$
[Sugerencia: Véase la ecuación (12) en la sección 6.4.]
