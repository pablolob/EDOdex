
## Enunciado

En los problemas 1-12, use la transformada de Laplace para resolver el sistema dado de ecuaciones diferenciales.

$$\begin{aligned}
\frac{dx}{dt} - 4x + \frac{d^3y}{dt^3} &= 6\sin t \\[1ex]
\frac{dx}{dt} + 2x - 2\frac{d^3y}{dt^3} &= 0
\end{aligned}$$
$$x(0) = 0, \quad y(0) = 0, \quad y'(0) = 0, \quad y''(0) = 0$$
