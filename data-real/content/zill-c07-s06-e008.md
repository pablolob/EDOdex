
## Enunciado

En los problemas 1-12, use la transformada de Laplace para resolver el sistema dado de ecuaciones diferenciales.

$$\begin{aligned}
\frac{d^2x}{dt^2} + \frac{dx}{dt} + \frac{dy}{dt} &= 0 \\[1ex]
\frac{d^2y}{dt^2} + \frac{dy}{dt} - 4\frac{dx}{dt} &= 0
\end{aligned}$$
$$x(0) = 1, \quad x'(0) = 0, \quad y(0) = -1, \quad y'(0) = 5$$
