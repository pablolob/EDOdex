
## Enunciado

En los problemas 5-8, use el método de Adams-Bashforth-Moulton para aproximar $y(1.0)$, donde $y(x)$ es la solución del problema con valores iniciales dado. Primero use $h = 0.2$ y después use $h = 0.1$. Use el método RK4 para calcular $y_1, y_2$ y $y_3$.
$$y' = y + \cos x, \quad y(0) = 1$$
