# ODEDEX para alumnos

Archivo de ejercicios de ecuaciones diferenciales.

Incluye 4331 ejercicios en Markdown, con o sin solución.

## Abrir la interfaz

Desde esta carpeta, inicia un servidor HTTP:

```powershell
python -m http.server 8000
```

Después abre <http://localhost:8000>.

La interfaz guarda capturas, notas y progreso en el navegador de cada alumno.
