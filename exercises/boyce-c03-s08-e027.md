## Enunciado

Para el problema con valor inicial del problema 26, trace la gráfica de $u$ contra $t$ para varios valores de $\gamma$ entre $1.75$ y $2.25$. Mediante el análisis de estas gráficas, intente determinar el valor de $\gamma$ para el que ocurre la transición de soluciones oscilatorias a no oscilatorias; es decir, intente determinar el valor crítico del coeficiente de amortiguamiento.
