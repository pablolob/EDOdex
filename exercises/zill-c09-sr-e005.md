## Enunciado

5. Aplique el método de Euler para aproximar $y(0.2)$, donde $y(x)$ es la solución del problema con valores iniciales $y'' - (2x + 1)y = 1, \quad y(0) = 3, \quad y'(0) = 1$. Primero use un paso con $h = 0.2$ y después repita los cálculos usando dos pasos con $h = 0.1$.
