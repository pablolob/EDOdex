## Enunciado

La figura 12.3.2(b) presenta la gráfica de $u(x, t)$ para $0 \le t \le 6$ para $x = 0$, $x = \pi/12$, $x = \pi/6$, $x = \pi/4$ y $x = \pi/2$. Describa o dibuje las gráficas de $u(x, t)$ sobre el mismo intervalo de tiempo pero para los valores fijos $x = 3\pi/4$, $x = 5\pi/6$, $x = 11\pi/12$ y $x = \pi$.
