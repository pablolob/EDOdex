## Enunciado

Use el método RK4 con $h = 0.1$ para aproximar $y(0.5)$, donde $y(x)$ es la solución del problema de valores iniciales $y' = (x + y - 1)^2$, $y(0) = 2$. Compare este valor aproximado con el valor real obtenido en el problema 11 de los ejercicios 9.1.
