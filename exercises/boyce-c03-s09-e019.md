## Enunciado

Los problemas 19 a 23 deben resolverse usando software de computadora con el que se tracen las gráficas de las soluciones de las ecuaciones diferenciales.

Considere el sistema forzado pero no amortiguado descrito por el problema con valor inicial

$$u'' + u = 3 \cos \omega t, \quad u(0) = 0, \quad u'(0) = 0.$$

Trace la gráfica de la solución $u(t)$ contra $t$ para $\omega = 0.7$, $\omega = 0.8$ y $\omega = 0.9$. Describa cómo cambia la respuesta $u(t)$ cuando $\omega$ varía en este intervalo. ¿Qué sucede cuando $\omega$ toma valores cada vez más próximos a uno? Observe que la frecuencia natural del sistema no forzado es $\omega_0 = 1$.
