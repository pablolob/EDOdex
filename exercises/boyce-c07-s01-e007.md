## Enunciado

Demuestre cada una de las siguientes leyes del álgebra matricial:
(a) $A + B = B + A$
(b) $A + (B + C) = (A + B) + C$
(c) $\alpha(A + B) = \alpha A + \alpha B$
(d) $(\alpha + \beta)A = \alpha A + \beta A$
(e) $A(BC) = (AB)C$
(f) $A(B + C) = AB + AC$
