## Enunciado

Dado que $x = \phi(t), y = \psi(t)$ es una solución del sistema autónomo
$$dx/dt = F(x, y), \quad dy/dt = G(x, y)$$
para $\alpha < t < \beta$, demuestre que $x = \Phi(t) = \phi(t - s), y = \Psi(t) = \psi(t - s)$ es una solución para $\alpha + s < t < \beta + s$.
