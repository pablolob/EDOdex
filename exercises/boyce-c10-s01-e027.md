## Enunciado

\text{Si } f(x) = \begin{cases} 1, & -l \le x < 0, \\ 0, & 0 \le x < l, \end{cases} \text{ y } f(x + 2l) = f(x)\text{, halle los coeficientes de la serie de Fourier correspondiente a } f \text{ al integrar sobre el intervalo } 0 \le x \le 2l\text{. Compare el resultado con el del problema 15.}
