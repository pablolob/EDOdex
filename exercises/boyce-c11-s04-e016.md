## Enunciado

Demuestre que el problema
$$y'' + \pi^2 y = \pi^2 x, \quad y(0) = 1, \quad y(1) = 0$$
tiene la solución
$$y = c_1 \sin \pi x + \cos \pi x + x.$$
También demuestre que esta solución no se puede obtener al dividir el problema como se sugirió en el problema 15, ya que en este caso no es posible resolver ninguno de los problemas subsidiarios.
