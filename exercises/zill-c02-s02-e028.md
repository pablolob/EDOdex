## Enunciado

En los problemas 23-28 encuentre una solución explícita del problema con valores iniciales dados.

$$(1 + x^4) \, dy + x(1 + 4y^2) \, dx = 0, \quad y(1) = 0$$

## Solución

La solución explícita del PVI es

$$y(x) = \frac{1 - x^2}{2(1 + x^2)}, \qquad x \in \mathbb{R}.$$

## Resolución

Se reescribe la ecuación en forma separable:

$$(1 + x^4)\, dy = -x(1 + 4y^2)\, dx.$$

Para $1 + 4y^2 \neq 0$ (siempre distinto de cero) y $1 + x^4 \neq 0$:

$$\frac{dy}{1 + 4y^2} = -\frac{x}{1 + x^4}\,dx.$$

Se integran ambos miembros. La integral del miembro izquierdo es:

$$\int \frac{dy}{1 + 4y^2} = \frac{1}{2}\arctan(2y).$$

Para el miembro derecho se usa la sustitución $u = x^2$, $du = 2x\,dx$, con lo que $x\,dx = du/2$:

$$-\int \frac{x}{1 + x^4}\,dx = -\int \frac{1}{1 + u^2}\cdot\frac{du}{2} = -\frac{1}{2}\arctan(u) = -\frac{1}{2}\arctan(x^2).$$

Igualando:

$$\frac{1}{2}\arctan(2y) = -\frac{1}{2}\arctan(x^2) + C.$$

Se multiplica por $2$:

$$\arctan(2y) = -\arctan(x^2) + 2C.$$

Se aplica la condición inicial $y(1) = 0$:

$$\arctan(0) = -\arctan(1) + 2C \;\Longrightarrow\; 0 = -\frac{\pi}{4} + 2C \;\Longrightarrow\; 2C = \frac{\pi}{4}.$$

Por tanto,

$$\arctan(2y) = \frac{\pi}{4} - \arctan(x^2) = \arctan(1) - \arctan(x^2).$$

Se aplica la identidad $\arctan(a) - \arctan(b) = \arctan\!\left(\frac{a - b}{1 + ab}\right)$, válida para $ab > -1$:

$$\arctan(2y) = \arctan\!\left(\frac{1 - x^2}{1 + x^2}\right).$$

Tomando la tangente en ambos miembros:

$$2y = \frac{1 - x^2}{1 + x^2},$$

$$y(x) = \frac{1 - x^2}{2(1 + x^2)}.$$

La solución está definida para todo $x \in \mathbb{R}$, ya que el denominador $1 + x^2$ nunca se anula y la condición $ab = x^2 > -1$ se cumple para todo $x$ real.

## Observaciones

La ecuación no posee soluciones constantes singulares porque el factor $1 + 4y^2$ nunca se anula en $\mathbb{R}$. La sustitución $u = x^2$ simplifica notablemente la integral del miembro derecho.
