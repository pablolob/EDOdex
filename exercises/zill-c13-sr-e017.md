## Enunciado

Determine la temperatura de estado estable $u(r, z)$ en un cilindro finito definido por $0 \le r \le 1, 0 \le z \le 1$ si las condiciones de frontera son
$$u(1, z) = u_0, \quad 0 < z < 1$$
$$u(r, 0) = 0, \quad \left.\frac{\partial u}{\partial z}\right|_{z=1} = 0, \quad 0 < r < 1.$$
[Sugerencia: Utilice $\lambda$ como la constante de separación en (13) de la sección 13.2.]
