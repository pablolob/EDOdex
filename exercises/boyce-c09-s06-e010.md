## Enunciado

10. Aplique el teorema 9.7.2 para demostrar que el sistema autónomo lineal

$$dx/dt = ax + by, \quad dy/dt = cx + dy$$

no tiene una solución periódica (diferente de $x = 0, y = 0$) si $a + d \neq 0$.
