## Enunciado

6. Utilice el método de Adams-Bashforth-Moulton para aproximar $y(0.4)$, donde $y(x)$ es la solución del problema con valores iniciales $y' = 4x - 2y, \quad y(0) = 2$. Use $h = 0.1$ y el método de RK4 para calcular $y_1, y_2$ y $y_3$.
