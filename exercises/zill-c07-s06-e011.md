## Enunciado

En los problemas 1-12, use la transformada de Laplace para resolver el sistema dado de ecuaciones diferenciales.

$$\begin{aligned}
\frac{d^2x}{dt^2} + 3\frac{dy}{dt} + 3y &= 0 \\[1ex]
\frac{d^2x}{dt^2} + 3y &= te^{-t}
\end{aligned}$$
$$x(0) = 0, \quad x'(0) = 2, \quad y(0) = 0$$
