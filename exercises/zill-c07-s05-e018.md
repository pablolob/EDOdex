## Enunciado

Lea i) en los Comentarios al final de esta sección. Luego use la transformada de Laplace para resolver el problema de valor inicial:

$$y'' + 4y' + 3y = e^t \delta(t - 1), \quad y(0) = 0, \quad y'(0) = 2.$$

Utilice una utilería de graficación para trazar la gráfica de $y(t)$ para $0 \le t \le 5$.
