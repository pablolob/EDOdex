## Enunciado

En los problemas 9-14, use la transformada de Laplace para resolver el problema con valores iniciales dado. Use la tabla de transformadas de Laplace del apéndice C cuando sea necesario.
$$y'' + 16y = f(t), \quad y(0) = 0, \quad y'(0) = 1, \quad \text{donde}$$
$$f(t) = \begin{cases} \cos 4t, & 0 \le t < \pi \\ 0, & t \ge \pi \end{cases}$$
