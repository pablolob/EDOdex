## Enunciado

En los problemas 61 y 62 resuelva el modelo para un sistema forzado resorte/masa con amortiguamiento
$$m\frac{d^2x}{dt^2} + \beta\frac{dx}{dt} + kx = f(t), \quad x(0) = 0, \quad x'(0) = 0,$$
donde la función forzada $f$ es como se especifica. Utilice un programa de graficación para trazar $x(t)$ en los valores indicados de $t$.

$m = 1$, $\beta = 2$, $k = 1$, $f$ es la función de onda cuadrada del problema 54 con amplitud $5$, y $a = \pi$, $0 \le t < 4\pi$.
