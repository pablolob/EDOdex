## Enunciado

Si $f(x) = \begin{cases} x + 1, & -1 < x < 0, \\ x, & 0 < x < 1, \end{cases}$ y $f(x + 2) = f(x)$, encuentre una fórmula para $f(x)$ en el intervalo $1 < x < 2$; y en el intervalo $8 < x < 9$.
