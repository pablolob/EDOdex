## Enunciado

Si $f(x) = \begin{cases} 1, & -l \le x < 0, \\ 0, & 0 \le x < l, \end{cases}$ y $f(x + 2l) = f(x)$, halle los coeficientes de la serie de Fourier correspondiente a $f$ al integrar sobre el intervalo $0 \le x \le 2l$. Compare el resultado con el del problema 15.
