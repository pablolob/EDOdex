## Enunciado

¿Cómo se debe extender $f$, originalmente definida sobre $[0, l]$, de modo que se obtenga una serie de Fourier que comprenda las funciones $\cos(\pi x/2l), \cos(3\pi x/2l), \cos(5\pi x/2l), \dots$? Consulte los problemas 38 y 39. Si $f(x) = x$ para $0 \le x \le l$, trace la gráfica de la función hacia la cual converge la serie de Fourier para $-4l \le x \le 4l$.
