## Enunciado

Con la aplicación del método del problema 35 y la solución particular dada, resuelva cada una de las siguientes ecuaciones de Riccati.

a) $y' = 1 + x^2 - 2xy + y^2; \quad y_1(x) = x$

b) $y' = -\frac{1}{x^2} - \frac{y}{x} + y^2; \quad y_1(x) = \frac{1}{x}$

c) $\frac{dy}{dx} = \frac{2\cos^2 x - \sin^2 x + y^2}{2\cos x}; \quad y_1(x) = \sin x$
