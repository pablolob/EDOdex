## Enunciado

En cada uno de los problemas 17 a 20, use una computadora para graficar el campo direccional. Obtenga una conclusión acerca del comportamiento de las soluciones cuando $x \to \infty$. Para comprobar la conclusión a la que llegó, resuelva la ecuación diferencial y después tome el límite cuando $x \to \infty$. $$y' + 3y = x + e^{-2x} \quad (\text{Problema } 1)$$
