## Enunciado

\text{Si } f(x) = \begin{cases} x + 1, & -1 < x < 0, \\ x, & 0 < x < 1, \end{cases} \text{ y } f(x + 2) = f(x)\text{, encuentre una fórmula para } f(x) \text{ en el intervalo } 1 < x < 2\text{; y en el intervalo } 8 < x < 9.
