## Enunciado

a) Encuentre los valores de $k_1 < 0$ para los cuales el sistema del problema 11 es oscilatorio.

b) Considere el problema con valores iniciales
$$x'' + x + k_1x^3 = \cos \frac{3}{2}t, \quad x(0) = 0, \quad x'(0) = 0.$$
Encuentre valores para $k_1 < 0$ para los cuales el sistema es oscilatorio.
