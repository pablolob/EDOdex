## Enunciado

Tarea para el laboratorio de computación

Líneas de flujo

a) La solución de la ecuación diferencial
$$\frac{2xy}{(x^2 + y^2)^2}\,dx + \left[1 + \frac{y^2 - x^2}{(x^2 + y^2)^2}\right] dy = 0$$
es una familia de curvas que se pueden interpretar como líneas de flujo de un fluido que discurre alrededor de un objeto circular cuya frontera está descrita por la ecuación $x^2 + y^2 = 1$. Resuelva esta ED y observe que la solución $f(x,y) = c$ para $c = 0$.

b) Use un SAC para dibujar las líneas de flujo para $c = 0, \pm 0.2, \pm 0.4, \pm 0.6$ y $\pm 0.8$ de tres maneras diferentes. Primero, utilice el contourplot de un SAC. Segundo, despeje $x$ en términos de la variable $y$. Dibuje las dos funciones resultantes de $y$ para los valores dados de $c$, y después combine las gráficas. Tercero, utilice el SAC para despeje $y$ de una ecuación cúbica en términos de $x$.
