## Enunciado

Demuestre que la solución del problema con valor inicial

$$mu'' + \gamma u' + ku = 0, \quad u(t_0) = u_0, \quad u'(t_0) = u_0'$$

puede expresarse como al suma $u = v + w$, en donde $v$ satisface las condiciones iniciales $v(t_0) = u, v'(t_0) = 0, w$ satisface las condiciones $w(t_0) = 0, w'(t_0) = u_0'$ y tanto $v$ como $w$ satisfacen la misma ecuación diferencial $u$. Este es otro caso de superposición de soluciones de problemas más simples para obtener la solución de un problema más general.
