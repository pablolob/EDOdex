## Enunciado

a) Encuentre un término diferente de cero para cada una de las soluciones $y_1(x)$ y $y_2(x)$ del ejemplo 8.

b) Determine una solución en serie $y(x)$ del problema de valor inicial $y'' + (\cos x)y = 0$, $y(0) = 1$, $y'(0) = 1$.

c) Use un SAC para trazar las gráficas de las sumas parciales $S_N(x)$ para la solución $y(x)$ del inciso b). Use $N = 2, 3, 4, 5, 6, 7$.

d) Compare las gráficas obtenidas en el inciso c) con la curva obtenida usando un programa de solución numérica para el problema con valores iniciales del inciso b).
