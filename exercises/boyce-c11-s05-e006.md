## Enunciado

Halle la temperatura de estado estable en una barra semiinfinita $0 < z < \infty, 0 \le r < 1$, si la temperatura es independiente de $\theta$ y tiende a cero cuando $z \to \infty$. Suponga que la temperatura $u(r, z)$ satisface las condiciones en la frontera

$$u(1, z) = 0, \quad z > 0,$$

$$u(r, 0) = f(r), \quad 0 \le r \le 1.$$

Sugerencia: consulte el problema 5.
