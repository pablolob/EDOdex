## Enunciado

En los problemas 1-12, use la transformada de Laplace para resolver el sistema dado de ecuaciones diferenciales.

$$\begin{aligned}
\frac{dx}{dt} + x - \frac{dy}{dt} + y &= 0 \\[1ex]
\frac{dx}{dt} + \frac{dy}{dt} + 2y &= 0
\end{aligned}$$
$$x(0) = 0, \quad y(0) = 1$$
