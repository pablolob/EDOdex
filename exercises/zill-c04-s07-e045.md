## Enunciado

Las condiciones iniciales $y(0) = y_0, y'(0) = y_1$ se aplican a cada una de las siguientes ecuaciones diferenciales:
$$x^2 y'' = 0,$$
$$x^2 y'' - 2x y' + 2y = 0,$$
$$x^2 y'' - 4x y' + 6y = 0.$$
¿Para qué valores de $y_0$ y $y_1$ cada problema con valores iniciales tiene una solución?
