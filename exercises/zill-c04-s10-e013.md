## Enunciado

Considere el problema con valores iniciales
$$y'' + yy' = 0, \quad y(0) = 1, \quad y'(0) = -1.$$
a) Use la ED y un programa de solución numérica para trazar la curva solución.
b) Encuentre una solución explícita del PVI. Use un programa de graficación para trazar la solución.
c) Determine un intervalo de definición para la solución del inciso b).
