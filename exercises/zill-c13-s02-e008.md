## Enunciado

Determine las temperaturas de estado estable $u(r, z)$ en el cilindro circular definido por $0 \le r \le 1$, $0 \le z \le 1$ si las condiciones de frontera son
$$u(1, z) = z, \quad 0 < z < 1$$
$$\left.\frac{\partial u}{\partial z}\right|_{z=0} = 0, \quad \left.\frac{\partial u}{\partial z}\right|_{z=1} = 0, \quad 0 < r < 1.$$
