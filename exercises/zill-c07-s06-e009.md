## Enunciado

En los problemas 1-12, use la transformada de Laplace para resolver el sistema dado de ecuaciones diferenciales.

$$\begin{aligned}
\frac{d^2x}{dt^2} + \frac{d^2y}{dt^2} &= t^2 \\[1ex]
\frac{d^2x}{dt^2} - \frac{d^2y}{dt^2} &= 4t
\end{aligned}$$
$$x(0) = 8, \quad x'(0) = 0, \quad y(0) = 0, \quad y'(0) = 0$$
