## Enunciado

En los problemas 15 y 16 una viga uniforme de longitud $L$ tiene una carga concentrada $w_0$ en $x = \frac{1}{2}L$. Véanse la figura 7.5.5 (problema 15) y la figura 7.5.6 (problema 16). Use la transformada de Laplace para resolver la ecuación diferencial

$$EI \frac{d^4y}{dx^4} = w_0 \delta\left(x - \frac{1}{2}L\right), \quad 0 < x < L,$$ 

sujeto a las condiciones frontera dadas.

$$y(0) = 0, \quad y'(0) = 0, \quad y''(L) = 0, \quad y'''(L) = 0$$
