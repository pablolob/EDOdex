## Enunciado

\text{Si } f(x) = x \text{ para } -l \le x < l \text{ y } f(x + 2l) = f(x)\text{, halle los coeficientes de la serie de Fourier correspondiente a } f \text{ al integrar sobre el intervalo } 0 \le x \le 2\text{. Compare el resultado con el del problema 17.}
