## Enunciado

Determine si existe algún valor de la constante $a$ para el que el problema tiene una solución. Encuentre la solución para cada uno de esos valores.

$$y'' + 4\pi^2 y = a + x, \quad y(0) = 0, \quad y(1) = 0$$
